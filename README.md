## AI Engineering

### [AI Research Assistant — Agentic RAG Platform](https://github.com/stevephilipgit/research-agent-rag-app)

A high-performance **agentic RAG platform** designed for research and knowledge retrieval across document collections.

The system goes beyond basic document chat by combining **LangGraph orchestration, hybrid retrieval, reranking, grounding validation, security guardrails, telemetry, caching, and multi-user isolation**.

**Key Work**

* Designed a state-driven LangGraph agent workflow
* Implemented hybrid semantic + BM25 retrieval
* Added reranking and context compression
* Built multi-user/session data isolation
* Implemented grounding validation to reduce unsupported answers
* Added retrieval telemetry and streaming responses
* Added rate limiting, caching and automated maintenance
* Containerized the complete application

**Stack:** `Python` `FastAPI` `React` `LangGraph` `Qdrant` `Supabase` `PostgreSQL` `Upstash Redis` `Docker` `Groq`

### [AgentFlow — Multi-Agent AI Platform](https://github.com/stevephilipgit/agentflow)

A multi-agent AI orchestration platform where a planner decomposes a goal into subtasks, specialist agents execute them in parallel, and a synthesizer generates the final executive report.

```text
User Goal
    |
    v
Planner
    |
    +------------+------------+------------+
    |            |            |            |
 Analyst      Engineer    Strategist   Risk Auditor
    |            |            |            |
    +------------+------------+------------+
                 |
                 v
            Synthesizer
                 |
                 v
          Executive Report
```

**Key Work**

* Planner → specialist workers → synthesizer architecture
* Structured JSON task generation
* Parallel asynchronous execution
* Rate-limit handling and retry backoff
* PDF/HTML report generation
* Serverless API architecture
* Reduced multi-agent execution to approximately 30 seconds

**Stack:** `React` `Vite` `JavaScript` `Groq` `Llama 3.3 70B` `Vercel Serverless` `Promise.all`

# Machine Learning & Data Science

### [Olist Brazil — Late Delivery Prediction](https://github.com/stevephilipgit/olsit_model_development)

A separate **machine learning project derived from the Olist Brazilian E-Commerce dataset**, focused specifically on predicting whether an order will be delivered late.

This is distinct from the Olist analytics project below.

```text
Olist Dataset
      |
      v
Data Cleaning
      |
      v
Feature Engineering
      |
      v
Leakage Audit
      |
      v
XGBoost Models
      |
      v
Class Imbalance Handling
      |
      v
Threshold Optimization
      |
      v
Probability Calibration
      |
      v
Error Analysis
      |
      v
Final Prediction Model
```

**Key Work**

* Formulated `late_delivery_flag` as a classification target
* Built prediction-time feature allow-lists
* Audited and removed leakage-prone post-outcome features
* Handled the 7.87% late-delivery class imbalance
* Compared multiple XGBoost configurations
* Optimized classification thresholds
* Performed cost-sensitive analysis
* Applied probability calibration
* Performed error and metric analysis

**Final Model:** Calibrated XGBoost V2

**Final Metrics**

| Metric    | Result |
| --------- | -----: |
| Accuracy  | 88.71% |
| Precision | 32.93% |
| Recall    | 41.92% |
| F1        | 36.89% |
| ROC AUC   | 79.29% |
| PR AUC    | 31.02% |

**Stack:** `Python` `Pandas` `NumPy` `Scikit-learn` `XGBoost` `Jupyter` `Power BI` `Docker`
